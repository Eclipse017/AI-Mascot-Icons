# AI 娘图标换装 v1.1.0

Windows 桌面快捷方式图标换装工具，内置 ChatGPT、Claude、Gemini、Grok、DeepSeek、ZCode、豆包（含经典红围巾与工作双皮肤）、MiniMax、WorkBuddy、Kimi 十位角色（11 款内置图标）。

## 下载与使用

1. 在下方 **Assets** 下载 **AI-Mascot-Icons-v1.1.0-windows.zip**。
2. 全部解压，双击 **AI-Mascot-Icons.exe**。
3. 勾选快捷方式、选择角色（豆包卡片右上角可切换 `经典` / `工作` 皮肤），然后应用；需要恢复时勾选原项目并点恢复。

程序包约 3.8 MB，免安装、离线使用，不需要登录或 API Key。自动保留首次修改前的完整备份，支持自定义 ICO、按行单独微调和批量换装。

## v1.1.0 主要更新

- **新增 6 款图标并扩展至 10 位角色 / 11 款内置图标**：新增 ZCode 娘、豆包经典红围巾皮肤、豆包工作娘、MiniMax 娘、WorkBuddy 混元娘与 Kimi 娘。
- **豆包卡内双皮肤切换**：保持宽屏 5×2 对称十卡片布局，豆包卡片支持一键切换 `经典` 与 `工作` 皮肤；列表下拉与批量匹配分别支持普通 `豆包`（经典）与 `豆包工作`（含混用中英文工作变体）。
- **卡片备注统一规范**：十一张图标备注统一为 `4字特征 · 简短产品名` 格式。
- **高 DPI 小屏与窄屏自适应布局**：窗口最小尺寸下限降至 `600×360` 并按工作区上限约束，窄屏自动调整卡片列数（4/3/2 列），矮屏下角色区滚动或自动/手动“收起/展开角色”以保证快捷方式列表与“应用 / 恢复”按钮完整可见，并分离跨屏拖动与尺寸约束。
- **批量匹配防误勾选**：优先匹配明确产品名（冲突时跳过），中文名与别名采用完整词或有依据产品组合匹配，避免 `glmnet`、`海螺 - 水泥报价`、`元宝 - 记账`、`混元 太极`、`红豆包食谱`、`Gemini Notebook` 等误勾选。
- **预览解码缓存与状态同步**：内置图标预览按需解码并冻结缓存；`Rows.Clear()` 重置退订与空选择安全处理；单行下拉改选仅更新本行并同步底部待应用提示。

## 适用范围与验证

支持 Windows 本地 `.lnk` 快捷方式，需要 .NET Framework 4.7.2+（现代 Windows 10/11 通常自带）。v1.1.0 已在 Windows 10 22H2 隔离测试环境通过 248 项自动化检查（含 11 款图标 Windows Shell 解析误差 `1.773–3.301 / 255`、真实 `ComboBox` 改选与置空保护、及 `1520×900` 跨界/`880×560`/`720×560`/`640×560`/`640×360`/负坐标模拟工作区验证），不修改应用 EXE，不启动 Claude 或其他 AI 客户端。
